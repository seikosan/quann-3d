## Abstract

本发明提供一种基于多几何双边缘注意力网络的三维点云分类方法，基于注意力机制构建多几何双边缘注意力网络。该网络具有多几何增强模块、双边缘注意力模块和通道注意力模块。注意力机制使网络更好地关注输入数据中对预测更重要的部分，从而提升三维点云分类的精度。多几何增强模块考虑欧式空间特征和几何特征，在不同方向获取点云原始特征，以获得更多几何线索。双边缘注意力模块从低层几何输入中提取更有意义信息并适当加权从而聚合点特征。该双边缘注意力模块用两个不同分支分别有效学习局部和全局特征，最后连接两分支以聚合本地和全局上下文要素。通道注意力模块在最终输出中提取有意义信息和适当加权聚合点特征进行三维点云分类任务。

The present invention provides a three-dimensional point cloud classification method based on a multi-geometry dual-edge attention network, and constructs a multi-geometry dual-edge attention network based on an attention mechanism. The network has a multi-geometry enhancement module, a dual-edge attention module, and a channel attention module. The attention mechanism allows the network to better focus on the parts of the input data that are more important for prediction, thereby improving the accuracy of 3D point cloud classification. The multi-geometry enhancement module considers Euclidean spatial features and geometric features, and obtains point cloud original features in different directions to obtain more geometric clues. The dual-edge attention module extracts more meaningful information from low-level geometric inputs and weights them appropriately to aggregate point features. This dual-edge attention module uses two different branches to effectively learn local and global features respectively, and finally connects the two branches to aggregate local and global context elements. The channel attention module extracts meaningful information and appropriately weighted aggregated point features in the final output for 3D point cloud classification tasks.

Technical Field

The invention belongs to the technical field of point cloud data analysis, and particularly relates to a three-dimensional point cloud classification method based on a multi-geometric double-edge attention network.

Background

Due to the development of three-dimensional sensing technology, the acquisition of the point cloud becomes more convenient. Generally, three-dimensional point clouds may be collected in natural environments by scanners using physical touch or non-contact measurements, such as lidar, RGB-D cameras, scanners, and the like. The point cloud has been widely used in the fields of high-precision large scale Digital Elevation Model (DEM) fabrication, building three-dimensional modeling, earth surface coverage classification, object change monitoring, forest resource investigation, biomass estimation, infrastructure mapping, coastal zone measurement, mine measurement, disaster assessment, wetland mapping, urban planning, three-dimensional reconstruction, automatic driving, and robot fields. The point cloud classification is a basic work in the point cloud data processing process, and the premise of accurate monitoring is that the classification of an object needs to be accurately identified, for example, in the satellite remote sensing field. In the field of autopilot, vehicles need to resolve various objects (e.g., pedestrians and vehicles) in an outdoor scene and their motion states before making a reliable decision. Reconstructing and analyzing the 3D object of the surrounding environment is a precondition for navigating and manipulating the object for the robotic gripping task. Because of its tremendous research value, point cloud data classification has attracted extensive research interest to many scholars.

Deep learning is increasingly popular in analyzing point cloud data such as classification and segmentation due to large-scale learning capability, and the realization of reliable point cloud analysis in a deep learning mode has been widely focused. Unlike 2D images, the point clouds are irregular, unstructured, unevenly distributed, and large in data volume, making them difficult to process and analyze using conventional convolution methods. How to learn representation features effectively from an unstructured point cloud remains a challenging problem. At present, significant success of Convolutional Neural Networks (CNNs) is directly replicated onto point clouds, and many efforts explore different methods to improve three-dimensional point cloud processing, such as the original work PointNet [1], and PointNet++ [2] are all directed to processing unordered point clouds, enabling efficient end-to-end point feature learning. These works work well, but there are still difficulties in the handling of the point cloud. Effective local geometric feature correspondence cannot be established and information between points cannot be well utilized, which results in low accuracy of point cloud classification and segmentation.

Since the introduction of PointNet [1], deep learning of 3D point clouds has progressed rapidly. Because of the unique properties of 3D point clouds in the N-dimensional space, the network needs to keep their reordering unchanged. PointNet [1] and Deep Set [3] at the earliest point that this was a potential research problem, they used permutation invariant functions and permutation alike variable functions to process points, respectively, and map data to symmetric functions, resulting in the desired data representation. Inspired by PointNet, further research is advanced on PointNet ideas and applied to various fields. The graph convolutional neural network (GCN) [4] is a neural network that extends CNNs to graphs. The GCN is suitable for processing irregular data structures such as point clouds and the like. In the graph neural network DGCNN [5], the neighborhood points are treated as a local graph, and the graph is dynamically updated after each layer of the network, and local information is also added to the architecture. The network can dynamically view local areas in the space instead of global coordinates of the whole point cloud, which means that the network only focuses on local feature mining of the point cloud and ignores global features.

In addition, some problems of the existing three-dimensional point cloud classification method based on the direct point cloud still remain unsolved: 1) In addition to three-dimensional coordinates, more geometric cues can be provided for CNN-based feature learning; 2) How to let the network automatically learn a better representation from the abstract high-level feature space; 3) To address feature learning difficulties caused by unordered point clouds, many efforts have transformed three-dimensional point cloud data preprocessing into 2D images or three-dimensional representations, such as multi-view projection [6] and voxelization [7-9]. However, this tends to result in wasted time and space, the projection method causes information loss, and how to determine the number of best views is a problem. Although the voxel method can directly apply three-dimensional convolution to perform feature extraction, the improvement of resolution brings greater calculation cost. These methods generally have low generalization capability, high computational complexity, and serious loss of inherent geometric information in the conversion process. Methods of end-to-end learning using the original point cloud as input are therefore receiving increasing attention.

The actions and effects of the invention

According to the three-dimensional point cloud classification method based on the multi-geometric double-edge attention network, the multi-geometric double-edge attention network is constructed by adopting an attention mechanism, and the network is provided with a multi-geometric enhancement module, a double-edge attention module and a channel attention module. Point cloud classification is challenging because a limited number of points are discretely distributed in an infinite 3D space, each point being useful for the representation of the entire point cloud set. Previous studies have focused mainly on extracting local features and acquiring global information using symmetric functions, ignoring the spatial relationships between all points. But the attention mechanism widely applied in visual tasks can well solve the problem. The attention mechanism allows the model to focus on important areas to a greater extent than traditional convolutions, enabling the network to focus better on the more important parts of the input data for prediction.

Therefore, the embodiment adds the attention mechanism in the MGDNet, namely the multi-geometric double-edge attention network, so that the network can concentrate on learning the global context of the network, obtain more important point cloud characteristics, and further strengthen the network architecture, so that the network always uses the most important point cloud characteristics to execute the current task. As shown in fig. 2, the multi-geometric double-edge attention network of the present embodiment obtains sufficiently rich point cloud information as input through the multi-geometric feature enhancement module (MGEM in fig. 2), and provides more geometric clues to enrich CNN-based feature learning. And S2, inputting the unordered point set of the original point cloud into a multi-geometric double-edge attention network, and acquiring point cloud characteristics of the original point cloud in different directions through a multi-geometric enhancement module so as to generate multi-dimensional low-level geometric vectors.

In the existing three-dimensional point cloud classification method based on the direct point cloud, the inherent characteristics of the original point cloud are mostly taken as input, such as three-dimensional coordinates of the point cloud. However, the input information is too simple, which results in that key features cannot be completely extracted. To solve this problem, the present embodiment proposes Multi Geometry Enhancement Module (MGEM) to not only consider the european space feature but also introduce various geometric features, which acquire the original features of the point cloud in different directions, so that the learning features of the network in the subsequent high-level space can benefit from the geometric relationships in the low-level space, so as to obtain sufficiently rich input features.

The multi-geometry enhancement module of the present embodiment works under a collaborative mechanism between euclidean space and eigenvalue space geometric features, aiming at providing rich geometric relationship information in the underlying space for subsequent implicit geometric feature learning. A given point cloud X is represented as a set of three-dimensional point sets { P i I=1, 2,3, where, n, typically, each point P in the point cloud i Represented by it in three-dimensional coordinates. That is, each point P i From its coordinates P i ＝(x i ,y i ,z i ) Other representations of RGB information, intensity values, etc. may be included. In the conventional deep learning, the discrete point cloud only provides three-dimensional coordinates, and other geometric features related to the three-dimensional point cloud are newly created based on the motivation of the rich point cloud input features, so that more low-level geometric clues are provided for subsequent high-level feature learning.

FIG. 3 is a schematic diagram of the visual effect of the multi-geometry enhancement module in enhancing the geometry of the embodiment of the invention.

As shown in fig. 3, to expand the input of the original point cloud information, the multi-geometry enhancement module divides the three-dimensional point cloud space into a euclidean space (dark circle in the figure) and a eigenvalue space (light circle in the figure), and an anchor point (dark point in the dark circle in the figure) is given, where the neighbors of the anchor point in the euclidean space are the dark circle portions in the figure, and the neighbors in the eigenvalue space are the light circle portions. Normally, the convolution operation of 3D points in euclidean space only works on points of a local area, as indicated by dark circles. The synthetic data set adopts a ModelNet40 reference data set, and is most popular and widely authoritative in the use of point cloud analysis due to clean shape and good construction, and is widely applied to point cloud shape classification and surface normal estimation. However, because of the limited and unbalanced distribution of the various categories of training data, point cloud classification on the ModelNet40 dataset is very challenging. ModelNet40 contains 12311 CAD-generated mesh model compositions from 40 object classes, of which 9843 are used for training and the remaining 2468 are reserved for testing. Further, following the configuration in PointNet [1], experiments were performed by sampling uniformly from the mesh model, extracting 1024 and 2048 points, and moving them to the origin to rescale to form a unit sphere. In the experiment, only the three-dimensional coordinates of each point cloud sample input point are used as the input of the network model, and the Average Accuracy (AA) in each category and the total accuracy (OA) of all categories are used as evaluation indexes.

To further demonstrate the effectiveness and robustness of the classification network of the present invention, experiments were also performed on a real dataset, i.e. the ScanObjectNN dataset for the 3D point set classification task, which is a more powerful real world object dataset containing 15 classes of about 15k objects. Although it is less classified than ModelNet40, it is more practically challenging than synthesizing a dataset due to complex background, partial loss, and various variations of the real world. The ScanObjectNN dataset has several variables, each representing a different level of difficulty. The experiment selected PBT50RS as the data object, which is the most difficult case of ScanObjectNN data sets, involved a perturbed object with a translation of 50%, each perturbation variable consisting of five randomly sampled objects from the original ground truth object, including rotation and scaling. 1024 points are uniformly sampled in the experiment to serve as an input point cloud, and total accuracy (OA) and average classification accuracy (AA) are used as evaluation indexes.

In the test, the multi-geometry enhancement module expands the three-dimensional coordinates of each input point into a low-level geometry vector of 14 degrees. The expanded features were then connected through 4 cascaded double-edge attention modules (Dual-edge attention modules, DEAMs). The KNN algorithm is used in DEAM to retrieve each local point local neighbor (here k=20 best configuration), extracting advanced geometric features embedded in different dimensions (64, 128, 256) of space. To integrate information from different scales, the output feature maps of the DEAMs are connected together and further integrated into a 1024-dimensional representation through a mask generated by the global attention module. We then skillfully apply AMP and AAP to collect representative object features simultaneously to form a global embedding vector by which confidence scores for all possible classes can be regressed using three shared MLP layers (output 512, 256, c) (model net dataset c=40, scanobjectnn dataset c=15).

Random gradient descent (SGD) with momentum of 0.9 was used as a trained optimizer in the test, with batch sizes of 32, and 300 trained epochs, each with an initial learning rate of 0.1, were used, with the learning rate adjusted by cosine annealing until it was reduced to 0.001. Cosine annealing is a learning rate scheduler that has the effect of decreasing relatively quickly to a minimum and then increasing rapidly, starting from a larger learning rate. Furthermore, during training, the training data was augmented with random anisotropic scaling in the range [ -0.66,1.5], panning in the range [ -0.2,0.2], and no pre-processing data expansion or voting method was performed during testing. Finally, cross entropy is used between the prediction and the real label as a loss function.
