A computer-implemented method constructs a point cloud (106) of N points in a D-dimensional space from a task input (100), which is an ordered token sequence or the measured field values of a tabular record. Point features (300) and pair-geometry features (302) derived from the positions of point pairs are combined by a set aggregation independent of input order into one set representation, from which a reader (116) produces a task output (118). Explanation data is obtained from that same point cloud of the trained model by a point-removal effect (122), region naming (124) or region shift (126), without a separate explanation model. A single self-contained deployment package (904) carries INT8 quantized weights (704) with a quantization table (706) and a resolution table (708) mapping model input identities to human-readable labels, so that a package of 138.2 KB delivers a decision and its audit on an edge device.
