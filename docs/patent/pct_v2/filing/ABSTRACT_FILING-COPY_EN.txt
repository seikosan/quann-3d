A computer-implemented method constructs a point cloud of N points in a D-dimensional space from a task input, which is an ordered token sequence or the measured field values of a tabular record. Point features and pair-geometry features derived from the positions of point pairs are combined by a set aggregation independent of input order into one set representation, from which a reader produces a task output. Explanation data is obtained from that same point cloud of the trained model by a point-removal effect, region naming or region shift, without a separate explanation model. A single self-contained deployment package carries INT8 quantized weights together with a quantization table and a resolution table mapping model input identities to human-readable labels, so that a package of 138.2 KB delivers both a decision and its audit on an edge device.
